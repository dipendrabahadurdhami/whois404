# Dipendra Dhami | Portfolio

Personal portfolio built with React, Vite and Tailwind CSS, deployed to GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The GitHub Actions workflow builds the app and publishes `dist/` on every push to `main`.

## Edit content

All text, projects and links live in `src/data.js`. Colors are the CSS variables at the top of `src/index.css`. Replace `public/photo.jpg` and `public/Dipendra_Dhami_CV.pdf` to update the photo and CV.
